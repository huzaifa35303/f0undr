# f0undr. // The Operating System & Portfolio for Builders

A high-performance, dark-aesthetic digital atelier and knowledge operating system designed for founders, engineers, and creators.

Built with **React 19**, **Vite**, **TypeScript**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## ⚡ What is inside f0undr Hub?

### 1. 🌐 Portfolio & Overview (Main Page)
- **Manifesto & Atelier**: Tells the story of **f0undr**, why we exist, and what we build.
- **4 Operational Pillars**:
  1. *Permissionless Leverage* (Autonomous models, systems & code).
  2. *Obsessive Craft & Speed* (Sub-48hr functional prototypes, crisp micro-interactions).
  3. *Open Knowledge Vaults* (Systematically cataloged takeaways & digests).
  4. *Long-Term Infinite Games* (Positive-sum relationships & continuous compounding).
- **Shipped Ventures & Portfolio**: Cards showcasing active products (*f0undr Hub*, *Cognitive Matrix Agent SDK*, *HyperScale Ledger*, *Aura Terminal*) with live stage badges and metrics.

### 2. 👥 f0undr Team
- **Core Collective Roster**: Profiles for founders and leads (Usman, Huzaifa, and team).
- **Live Status Telemetry**: `Building`, `Deep Work`, `Available`, `Offline` indicator badges with pulsing beacons.
- **Detailed Profiles**: Full bio, technical mastery skill pills, philosophy quote, and direct social links (GitHub, X / Twitter, LinkedIn, Email).
- **Interactive Add Member**: Add new team members or collaborators with full form validation.

### 3. 📚 Bookshelf & Reading Vault
- **11+ Curated Founder Books**:
  - *Zero to One*, *Naval Ravikant*, *High Output Management*, *Designing Data-Intensive Applications*, *Chip War*, *Atomic Habits*, *The Hard Thing About Hard Things*, *Steve Jobs*, *The Psychology of Money*, *Build*, *Superintelligence*.
- **Filter by Category**: Startups & Business, AI & Technology, Philosophy, Design, Biographies, Productivity.
- **Filter by Reading Status**: Currently Reading, Completed, Wishlist.
- **Interactive Book Reader Modal**: Read key strategic takeaways, personal founder notes, and quotes.
- **Add New Books**: Easily add custom books with notes, ratings, and custom categories.

### 4. 🧰 The Founder Toolbox
- **Built-in Interactive Utilities**:
  1. **Pomodoro Deep-Work Focus Timer**: 25m focus / 5m short break / 15m long break, custom session tracking, Web Audio synthesizer chime, and confetti celebration.
  2. **Founder Markdown Scratchpad**: Real-time autosaving notes editor, word/char counters, formatting buttons, and one-click `.md` export.
  3. **Startup Idea Viability Matrix**: 5-vector evaluation tool (Urgency, Willingness to Pay, Unfair Advantage, Distribution, Moat) that calculates an instant viability score (0-100%) and exportable brief.
  4. **SaaS & Venture Economics Forecaster**: Live calculator computing MRR, ARR, LTV, CAC, LTV/CAC ratio, and CAC payback period.
- **Curated Tools Directory**: Searchable catalog of 14+ essential developer and AI tools (*Cursor, v0, Supabase, Raycast, Linear, Claude, Perplexity, Figma, Framer, Obsidian, etc.*) with quick-launch links.

### 5. 🎒 Things, Setup & Gear
- Curated showcase of hardware, desk setups, everyday carry tools, and physical artifacts (*M-Series Silicon, 75% Mechanical Keyboard, Sony ANC, 5K2K Display, Kindle Scribe, Aeron, Field Notes*).

### 6. 🔍 Global Search & Local Data Ownership
- **Command Palette (`Ctrl+K` / `⌘K`)**: Instant search across all books, tools, team members, and artifacts simultaneously.
- **Local-First & Data Persistence**: Everything synchronizes with `localStorage`.
- **Export & Restore**: One-click JSON backup and restore to own your library forever.

## 🚀 Running the Project

```bash
# Navigate to project directory
cd d:/f0undr-web

# Install dependencies (if needed)
npm install

# Start development server
npm run dev -- --host
```

Open your browser at **`http://localhost:5173/`**.
